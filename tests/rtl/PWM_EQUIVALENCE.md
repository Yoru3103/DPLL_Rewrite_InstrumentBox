# PWM 比较流水级的逐周期等价回归

运行：

```powershell
./tests/rtl/run_pwm_equivalence.ps1
# 可用 -VivadoBin 指定其他 Vivado 2018.3 bin 路径。
```

输出位于被 Git 忽略的 `autotune_complete.sim/pwm_equivalence/`。成功标记：

```text
PASS: PWM cycle equivalence; 131072 comparison input pairs, FULL=0/1/15/16/156/255, cfg boundaries, synchronous reset and device INIT0
```

`pwm_reference.sv` 是提交 `1e4469a` 的原始 PWM RTL，仅改模块名用于并列实例化，并清除行尾空白。回归直接比较当前生产 PWM 与该参考，而不是重复实现新分段比较器。

本次修改用三个预计算谓词替换原 `vcnt_r/v_r` 中间级：高4位小于、高4位相等、低4位小于等于；下一拍仅组合这三个谓词。`pwm_target` 明确为8位，因此255加小数位1仍回卷为0，与原8位 `v_r` 赋值一致。没有新增输出延迟，也不改变计数、配置锁存、分数位移位或 `pwm_s`。新谓词寄存器声明初值为 `(0,1,1)`，对应旧 `vcnt_r=v_r=0` 时的比较结果；运行时reset分支仍不改写比较中间级。

测试覆盖：

- 将256种计数值 × 256种整数目标值 × 2种小数输入位送入实际 DUT，穷举131072种比较组合；断言刺激确实到达DUT，并累计唯一组合覆盖率。
- FULL为0、1、15、16、156（生产默认）、255的六个完整PWM实例同时与旧RTL逐周期对照。
- 整数配置0、1、15、16、155、156、157、254、255与五种小数位模式交叉；每组保持4200时钟，跨越所有实例的16周期配置更新边界。
- 再执行20000时钟的确定性随机配置、反复同步复位和5000时钟尾部运行。
- 每拍比较 PWM输出、同步输出、配置寄存器、计数器、整数/分数寄存器；在复位下降沿另行检查未引入异步清零。

原设计的 `v/b` 与比较中间寄存器没有RTL初值，也不在复位分支赋值。参考输出为X的启动区段没有确定逻辑行为，因此不作二态等价承诺；所有参考已定义的输出，包括再次复位和解除复位首拍，均比较。另外增加独立的 `MODEL_DEVICE_INIT` 实例：在测试环境一次性force/release原寄存器与其余FF为0，模拟Vivado器件INIT0；新谓词初值直接取自生产RTL声明。该实例从首拍起不允许参考输出X，并逐拍比较包括上电解除复位的输出。旧impl_1布线检查点已核对：四通道的v_r与vcnt_r共64个直接命名寄存器均为INIT=0，未发现信号反相转换，证据保存在autotune_complete.sim/read_pwm_original_init.log；仿真不代替布线时序与板上输出验证。该模块没有独立enable输入。

2026-09-20：Vivado 2018.3 XSim通过，仿真结束时间1712032ns；参考源与1e4469a逐字比对一致（忽略测试头注释与模块重命名）。
